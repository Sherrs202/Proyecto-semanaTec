### Descripción de las modificaciones

**1. Contador de parejas descubiertas**

Se implementó un contador que registra y muestra en la terminal
el número de parejas encontradas durante el juego.

**2. Detección del final del juego**

Se agregó una condición que identifica cuando todas las parejas
han sido descubiertas y muestra un mensaje de felicitación al jugador.

**3. Reducción del tablero de 8×8 a 4×4**

Se modificó el tablero original de 8×8 a 4×4, reduciendo el
número de casillas de 64 a 16 y actualizando las funciones
necesarias para su funcionamiento.
