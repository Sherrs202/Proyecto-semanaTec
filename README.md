Realize modificaciones de cambiar el tablero, la comida y velocidad de fantasmas

Andrea Sofia Nava Nieto A01710468
Videojuego: Memory
Descripción de modificaciones:
  1-. Contador de parejas descubiertas: En esta seccion se implemento un contador que registrara y posteriormente mostrara en la terminal el número de pares encontrados a lo largo del juego.
  2-. Detectar cuando todos los cuadros se han destapado: Se agrego una condición que identifica cuando todas las parejas han sido descubiertas y muestra un mensaje de felicitación al jugador.
  3-. Reducción de casillas del tablero: Se modificó el tablero original de 8×8 a 4×4, reduciendo el número de casillas de 64 a 16 y actualizando las funciones necesarias para su funcionamiento.
